## 💻 Featured Projects

### 🎓 [Who Should a College Help First?](https://github.com/asthram08/student-dropout-risk-fairness)
A dropout risk model with a **fairness audit**, built on 4,424 college students. It turns predictions into an outreach plan: who to contact first and what kind of help they need.
- Contacting the **top 10% highest-risk students reaches 31% of all dropouts**, vs. 10% at random
- Logistic regression catches **81% of dropouts** (ROC AUC **0.913**)
- The audit found more false alarms for students 25+ and that the model misses 41% of scholarship holders who drop out
- **Tech:** Python · scikit-learn · pandas · Streamlit · [**Live app**](https://student-dropout-risk-fairness.streamlit.app/)

### 🛒 [Why Don't Shoppers Come Back?](https://github.com/asthram08/ecommerce-retention-analysis)
A product analytics teardown of **20.7 million e-commerce events**, written up as a one-page memo for a PM.
- Cleaned **1.2M bad rows** and built sessions, orders, and users tables from raw clickstream logs
- Found **92% of new shoppers don't return** the next week, and shoppers with bigger first orders buy again at **twice the rate**
- **Tech:** SQL · DuckDB · Python

### 🚗 [Spartan Park](https://github.com/asthram08/spartan-park) · *in progress*
Predicts how full SJSU parking garages will be, so students know where to park before they leave home.
- Automated data collector running on **GitHub Actions** since Oct 2026
- App launch planned for **Spring 2027**
- **Tech:** Python · GitHub Actions

### 🚀 [SpaceX Falcon 9 Landing Prediction](https://github.com/asthram08/spacex-capstone)
Capstone for the IBM Data Science Professional Certificate. Predicts whether a Falcon 9 first stage will land successfully.
- **Tech:** Python · SQL · machine learning
